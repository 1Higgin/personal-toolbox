PERSONAL TOOLBOX — ANDROID INSTALL PACKAGE

This folder is prepared for free static HTTPS hosting (for example GitHub Pages).
Upload the CONTENTS of this folder to the root of a repository, enable GitHub Pages, then open the resulting https:// address in Brave on Android.
In Brave, open the site menu and choose Install app or Add to Home screen.

The app caches its files for offline use. Ideas, projects and notes are stored in the browser storage on that phone. Use Export backup in App info regularly.
